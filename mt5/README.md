# GoldCast MT5 Export — ดึงข้อมูล OHLC ทุกตลาดเป็น CSV ในคลิกเดียว

สคริปต์ `GoldCast_Export.mq5` สำหรับ MetaTrader 5 ที่ export ข้อมูล OHLC
ของทุกตลาดที่ GoldCast ใช้ (ทอง, ดัชนี, คู่เงิน) ออกเป็นไฟล์ CSV พร้อมกันทีเดียว
เลิกพิธีกรรม export ทีละตลาดทีละ timeframe ด้วยมือ

ไฟล์ที่ออกมา **รูปแบบตรงกับไฟล์ export เดิมของ pipeline เป๊ะ** —
คั่นด้วย TAB, จบบรรทัด CRLF, มี header `<DATE> <TIME> <OPEN> ...`,
วันที่ `YYYY.MM.DD`, เวลา `HH:MM:SS`, ทศนิยมตาม digits ของ symbol,
และคอลัมน์ `<TICKVOL> <VOL> <SPREAD>` (SPREAD เป็นหน่วย point เหมือนเดิม)
นำไปอัปโหลด/ใช้แทนไฟล์เดิมได้ทันทีโดยไม่ต้องแปลงอะไร

## วิธีติดตั้งและใช้งาน (ทีละขั้น)

1. **คัดลอกสคริปต์เข้า MT5**
   - เปิด MT5 → เมนู **File → Open Data Folder**
   - เข้าโฟลเดอร์ `MQL5/Scripts/` แล้ววางไฟล์ `GoldCast_Export.mq5` ลงไป
   - (หรือดาวน์โหลดจากแอป GoldCast ถ้ามีลิงก์ให้)

2. **Compile**
   - เปิด MetaEditor (กด F4 จาก MT5) → เปิดไฟล์ `GoldCast_Export.mq5` → กด **F7**
   - ควรเห็น `0 errors, 0 warnings` ในแท็บ Errors

3. **รัน**
   - ใน MT5 เปิดหน้าต่าง **Navigator** (Ctrl+N) → กลุ่ม **Scripts**
   - ลาก **GoldCast_Export** ลงบน chart อะไรก็ได้ (หรือดับเบิลคลิก)
   - หน้าต่าง input จะเด้งขึ้นมา (ดูหัวข้อถัดไป) → กด **OK**

4. **รอผล + ตรวจ log**
   - เปิดแท็บ **Experts** ในหน้าต่าง Toolbox (Ctrl+T)
   - จะเห็นรายงานทีละไฟล์ เช่น
     `[GoldCast] GoldCast\XAUUSD_H1.csv → 27136 แถว (2022.01.03 01:00:00 ถึง ...)`
   - ปิดท้ายด้วยบรรทัดสรุปว่าสำเร็จกี่ไฟล์ รวมกี่แถว ข้าม/ล้มเหลวกี่รายการ

5. **เอาไฟล์ไปใช้**
   - ไฟล์อยู่ที่ **File → Open Data Folder → `MQL5/Files/GoldCast/`**
   - ชื่อไฟล์รูปแบบ `<SYMBOL>_<TF>.csv` เช่น `XAUUSD_D1.csv`, `XAUUSD_H1.csv`,
     `XAUUSD_M15.csv`, `US100_H1.csv`

## Input parameters

| Parameter | ค่าเริ่มต้น | ความหมาย |
|---|---|---|
| `InpSymbolMap` | `XAUUSD=XAUUSD,US100=US100,US30=US30,GER40=GER40,EURUSD=EURUSD,GBPUSD=GBPUSD,USDJPY=USDJPY` | คู่ `ชื่อมาตรฐาน=ชื่อ symbol ของโบรก` คั่นด้วยลูกน้ำ (v2 ลองชื่อสำรองให้เองถ้าหาไม่เจอ) |
| `InpTimeframes` | `D1,H1,M15` | timeframe ที่ export (รองรับ `M5,M15,M30,H1,H4,D1,W1,MN1`) |
| `InpFromDate` | `2021.12.01 00:00` | วันที่เริ่มดึงข้อมูล (ครอบช่วงข้อมูลเดิมของ pipeline ที่เริ่มราว 2021.12–2022.01) |
| `InpMaxBars` | `200000` | เพดาน bar ต่อไฟล์ (เกินจะตัดเอาชุดล่าสุด + เตือนใน log) |
| `InpSkipCurrentBar` | `true` | ข้าม bar ล่าสุดที่ยังไม่ปิด เพื่อให้ไฟล์มีแต่ bar สมบูรณ์ |
| `InpUploadEnabled` | `true` | ส่ง CSV ขึ้นเซิร์ฟเวอร์อัตโนมัติหลัง export แต่ละไฟล์เสร็จ |
| `InpUploadBaseUrl` | `https://goldcast-production.up.railway.app` | base URL ของเว็บ GoldCast (ต้องตรงกับที่เพิ่มใน WebRequest allow-list) |
| `InpUploadToken` | _(ว่าง)_ | PIN (ตรงกับ `UPLOAD_TOKEN` บน Railway) — ว่าง = ข้ามการอัปโหลด |
| `InpUploadTimeoutMs` | `20000` | timeout ของการอัปโหลดต่อไฟล์ (มิลลิวินาที) |

## ส่งไฟล์อัตโนมัติ (ตั้งค่าครั้งเดียว)

ตั้งแต่ v2 สคริปต์จะ POST ไฟล์ CSV ขึ้นเว็บ GoldCast เองทีละไฟล์หลัง export
เสร็จ — ไม่ต้อง zip ไม่ต้องอัปโหลดมือ ตั้งค่าครั้งเดียวตามนี้:

1. **เปิดสิทธิ์ WebRequest** — ใน MT5 ไปที่ **Tools → Options → Expert Advisors**
   → ติ๊ก **"Allow WebRequest for listed URL"** → เพิ่ม
   `https://goldcast-production.up.railway.app` เข้าไปในรายการ → กด OK
2. **ใส่ PIN** — ตอนรันสคริปต์ ใส่ PIN ในช่อง **`InpUploadToken`**
   (PIN เดียวกับ `UPLOAD_TOKEN` ที่ตั้งไว้บน Railway) — MT5 จำค่า Inputs
   ล่าสุดให้ รอบต่อไปไม่ต้องพิมพ์ใหม่
3. **รันปกติ** — ไฟล์จะบินขึ้นเว็บเอง ดูผลได้ในแท็บ Experts
   (`อัปโหลด ... สำเร็จ` ทีละไฟล์ + สรุป `อัปโหลดอัตโนมัติ: X/Y สำเร็จ` ท้ายรัน)

ถ้าลืมทำข้อ 1 สคริปต์จะเตือนใน Experts ว่ายังไม่ได้อนุญาต WebRequest
แล้ว export ไฟล์ลงดิสก์ต่อตามปกติ (เปิดสิทธิ์แล้วรันใหม่ได้เลย)
ถ้า PIN ผิดจะเจอ HTTP 403; ถ้าเซิร์ฟเวอร์ยังไม่ได้ตั้ง `UPLOAD_TOKEN` จะเจอ HTTP 501

> **หมายเหตุ:** อัปโหลดแล้วตัวเลขในเว็บ**ไม่เปลี่ยนทันที** —
> ไฟล์จะถูกเก็บไว้ให้ pipeline หยิบไป retrain รอบถัดไป รอรอบ retrain ก่อน
> ตัวเลขหน้าเว็บถึงจะขยับ

## ตารางแก้ชื่อ symbol ถ้าโบรกต่างจากค่าเริ่มต้น

แก้เฉพาะ **ฝั่งขวา** ของเครื่องหมาย `=` (ชื่อฝั่งซ้ายใช้เป็นชื่อไฟล์ผลลัพธ์)

| ตลาด (ชื่อมาตรฐาน) | ค่าเริ่มต้น | ตัวอย่างชื่อที่โบรกอื่นอาจใช้ |
|---|---|---|
| XAUUSD (ทอง) | `XAUUSD` | `XAUUSD.pro`, `GOLD`, `XAUUSD.a` |
| US100 (Nasdaq 100) | `US100` | `NAS100`, `USTEC`, `US100.cash`, `NDX` |
| US30 (Dow Jones) | `US30` | `DJ30`, `US30.cash`, `WS30` |
| GER40 (DAX) | `GER40` | `GER40.cash`, `DE40`, `DAX40`, `GER40.pro` |
| EURUSD | `EURUSD` | `EURUSD.pro`, `EURUSD.a` |
| GBPUSD | `GBPUSD` | `GBPUSD.pro`, `GBPUSD.a` |
| USDJPY | `USDJPY` | `USDJPY.pro`, `USDJPY.a` |

เช่น ถ้าโบรกใช้ `GOLD` กับ `NAS100` ให้ตั้งเป็น
`XAUUSD=GOLD,US100=NAS100,US30=US30,...`

> ดูชื่อ symbol ที่โบรกใช้จริงได้จากหน้าต่าง **Market Watch** (Ctrl+M)
> ถ้า symbol หาไม่เจอ สคริปต์จะข้ามและแจ้งในแท็บ Experts — ไม่ทำให้ตลาดอื่นพัง

**หมายเหตุชื่อไฟล์:** ไฟล์เดิมของ pipeline บางชุดใช้ชื่อ `NAS100_...`
และมีวันที่ต่อท้ายชื่อไฟล์ (เช่น `XAUUSD_Daily_202201030000_202608040000.csv`)
— สคริปต์นี้ตั้งชื่อสั้นกว่า (`US100_H1.csv`) ถ้าระบบปลายทางต้องการชื่อแบบเดิม
ให้ rename เองหลัง export (เช่น `US100` → `NAS100`, `D1` → `Daily`)

## ข้อจำกัด / ข้อควรรู้

- **MQL5 เขียนไฟล์ zip ไม่ได้** — ได้ CSV ดิบหลายไฟล์ในโฟลเดอร์ `GoldCast/`
  - ทางเลือก 1: คลิกขวาโฟลเดอร์ `GoldCast` → Send to → Compressed (zip) แล้วอัปโหลด
  - ทางเลือก 2: อัปโหลดทีละไฟล์ผ่านหน้า `/upload` ของแอป GoldCast
- **ข้อมูลย้อนหลังขึ้นกับโบรก** — ถ้าโบรกมี history สั้นกว่า `InpFromDate`
  ไฟล์จะเริ่มช้ากว่าที่ตั้งไว้ (ดูช่วงวันที่จริงจาก log ท้ายแต่ละบรรทัด)
- **ครั้งแรกอาจช้า** — terminal ต้องโหลด history จากเซิร์ฟเวอร์ก่อน
  (สคริปต์ลองซ้ำให้อัตโนมัติ 5 ครั้ง) ถ้าไฟล์ไหนล้มเหลว ให้รันซ้ำอีกรอบ
- **VOL เป็น 0 สำหรับ FX/CFD** — ปกติ เหมือนไฟล์เดิม (โบรกส่วนใหญ่ไม่มี real volume)
- **SPREAD เป็น point ณ ตอน bar นั้น** จากข้อมูลของโบรก — ไม่ใช่ spread ปัจจุบัน
- **timezone ของเวลาในไฟล์ = timezone เซิร์ฟเวอร์โบรก** เหมือนไฟล์ export เดิม
  ถ้าเปลี่ยนโบรก เวลาอาจเลื่อน 1–2 ชั่วโมง ตรวจแถวแรกเทียบไฟล์เก่าก่อนใช้งาน

## ความถี่ที่แนะนำ

- **รันสัปดาห์ละครั้ง หลังตลาดปิด** (เสาร์เช้า) — ได้ bar ครบสมบูรณ์ของสัปดาห์
  แล้วอัปโหลดเข้าแอปทีเดียว
- ถ้าต้องการรีเฟรชกลางสัปดาห์ ให้เปิด `InpSkipCurrentBar = true` ไว้เสมอ
  (ค่าเริ่มต้น) เพื่อไม่ให้ bar ที่ยังไม่ปิดหลุดเข้าไปในไฟล์
